# Customer Shopping Behavior Analysis

An end-to-end data analytics project exploring customer purchasing behavior and sales trends using Python, Excel, and Power BI.

## Project overview
- Dataset: 3,900 customer records
- Tools: Python (Jupyter Notebook), Excel, Power BI
- Topics: customer purchasing patterns, product categories, and sales insights

## Repository contents
- `Anfal_Atef.ipynb` — Python analysis notebook
- `Final_Project_dataset.csv` — dataset used by the notebook
- `Anfal_Excel_Analysis.xlsx` — Excel analysis
- `Anfal_Atef.pbix` — Power BI report (requires Power BI Desktop)
- `Anfal_Atef.docx` — project documentation

## Getting started
1. Download or clone the repository.
2. Open `Anfal_Atef.ipynb` in Jupyter Notebook or JupyterLab.
3. Keep `Final_Project_dataset.csv` in the same folder as the notebook.
4. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
